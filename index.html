📋 Endpoints

GET/health

Health check. Always returns 200 with version info.

{
  "status": "ok",
  "version": "1.0.0",
  "timestamp": "2026-05-09T..."
}
POST/api/format/json

Format and validate JSON. Parse, prettify, and validate JSON strings.

Body: {"text": "{\"name\":\"Jack\"}", "indent": 2}

{
  "success": true,
  "formatted": "{\n  \"name\": \"Jack\"\n}",
  "type": "dict",
  "length": 24
}
POST/api/validate/json

Validate JSON. Check if a string is valid JSON. Returns detailed errors.

POST/api/count/tokens

Count tokens. Estimate token count for any AI model.

Body: {"text": "Hello world", "model": "gpt-4"}

{
  "characters": 11,
  "words": 2,
  "model": "gpt-4",
  "estimated_tokens": 3
}

Models: GPT-4, GPT-3.5, Claude-3, Claude Sonnet 4, Llama-3, Gemini Pro, DeepSeek

POST/api/generate/qr

Generate QR code. Create QR codes in PNG, SVG, or base64 format.

Body: {"text": "https://example.com", "format": "base64"}

{
  "success": true,
  "format": "base64",
  "data_url": "data:image/png;base64,..."
}
POST/api/generate/palette

Color palette generator. Generate complementary, analogous, triadic, or monochromatic palettes.

Body: {"type": "complementary", "base_color": "#7c5cff"}

{
  "type": "complementary",
  "base_color": "#7c5cff",
  "colors": ["#7c5cff", "...", "..."],
  "preview_gradient": "linear-gradient(...)"
}
POST/api/domain/history

Domain history. Look up any website's history via Internet Archive Wayback Machine.

Body: {"domain": "example.com", "year": 2024}

{
  "domain": "example.com",
  "latest_snapshot": {
    "url": "https://web.archive.org/...",
    "timestamp": "20240509120000"
  }
}
POST/api/decode/jwt

Decode JWT. Decode JWT tokens without signature verification. Returns header, payload, metadata.

POST/api/keys/register

Get API key. Register for a free API key (100 requests/day).

{
  "api_key": "jsk_abc123...",
  "tier": "free",
  "daily_limit": 100
}

🔧 Usage Examples

cURL

curl -X POST https://api.jackstoolbox.dev/api/format/json \
  -H "Content-Type: application/json" \
  -d '{"text": "{\"name\":\"Jack\"}", "indent": 2}'

Python

import requests

response = requests.post(
    "https://api.jackstoolbox.dev/api/count/tokens",
    headers={"X-API-Key": "jsk_your_key_here"},
    json={"text": "Hello world", "model": "gpt-4"}
)
print(response.json())

JavaScript (fetch)

const res = await fetch("https://api.jackstoolbox.dev/api/generate/palette", {
  method: "POST",
  headers: {"Content-Type": "application/json"},
  body: JSON.stringify({type: "complementary", base_color: "#7c5cff"})
});
const data = await res.json();
console.log(data.colors);
